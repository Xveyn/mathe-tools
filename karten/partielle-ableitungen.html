Partielle Ableitungen

Eine Funktion zweier Veränderlicher wird nach einer Variablen abgeleitet, während die andere festgehalten wird. Was dabei geometrisch geschieht, zeigt sich an den Schnittkurven der Fläche.

Partielle Ableitung

f ist in einer Umgebung von (x0,y0) definiert, und der Grenzwert existiert.
fx (x0,y0) = ∂f ∂x = lim h→0 f(x0+h,y0) − f(x0,y0) h

Die partielle Ableitung nach x ist die Steigung der Schnittkurve z=f(x,y0) an der Stelle x0. Die andere Variable wird festgehalten.

f(x,y)=x2y+3y2

fx=2xy(y ist eine Zahl, 3y2 fällt weg)

fy=x2+6y(x ist eine Zahl)

An der Stelle (2,1):

fx(2,1)=2⋅2⋅1=4

fy(2,1)=22+6⋅1=10

Gegenprobe über die Schnittkurven:

Schnitt y=1: z=x2+3, z′=2x, bei x=2 also 4. ✓

Schnitt x=2: z=4y+3y2, z′=4+6y, bei y=1 also 10. ✓

Beim partiellen Ableiten ist die andere Variable eine Zahl.

∂∂x(3y2) ist 0, nicht 6y. Wer die falsche Variable festhält, bekommt beide Ableitungen vertauscht.

Gib dort x^2*y + 3y^2 ein und stelle die Regler y = c auf 1 und x = c auf 2. Dann sind die beiden unteren Ansichten genau diese Schnittkurven. Beide Regler stehen anfangs auf 0, und dort rechnet das Werkzeug etwas anderes vor: z=0 und z=3y2.
